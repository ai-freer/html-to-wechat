# HTML → AI 图集

图集继续使用 AI 生图，不改为代码绘卡。原文截图用于理解内容，不冒充最终 AI 卡片。已有批准的资产必须保留，不擅自重画。

## Agent contract

1. 读完整 HTML 并看截图，列出章节、关键论点与图表；不能只看前几屏就压缩长报告。
   拆卡前先写一段内容简报：原文主要想讲清什么？谁会读，他们已经知道什么？读完应能解释、辨别或做到什么？区分主旨与用来引入或举证的例子。读者未指定时依据原文推断并标明。再选能帮助这群读者理解的视觉表达，说明为什么适合；不要先定画风、套页序，再去填内容。
2. 按用户指定的平台和数量拆卡；未指定时以 8–10 张为参考，按内容增减。先锁定整组比例、目标尺寸和共用风格。在本次本地成果目录保存一份逐卡制作记录，每卡用稳定标识关联原文章节、读者应看懂的一句话、这页的作用、必须准确呈现的文字、素材出处及用途、alt 和完整 prompt。制作记录不写入分享链接。
   - 连读各页的一句话：前一页提出的问题，后面哪页回答？相邻两页若只是重复摘要，就合并或调整分工。可让一页说明判断、下一页用实物或数据验证；不要为了变换版式拆散同一条论证。
   - 对照简报指出哪张或哪几张卡能让读者达成阅读目标；若还要靠额外口头解释，先改分镜。用户要求先看规划时，在简报和分镜处交付。
   - 按论点选图：说明操作时保留真实界面的关键状态；解释机制时画清对象和方向；数值对比保留单位、尺度和比较条件。生成的场景图可帮助理解，不能冒充实拍、实测或真实截图。缺原始证据时，改作明确的示意或标注缺口。
3. Codex/ChatGPT 用宿主内置生图工具 GPT-Image 2；其他宿主使用用户明确指定且当前可用的生图能力。不要从旧 Skill 自动导入 API key、第三方服务或模型参数，也不假设 `anthropic-skills:gpt-image` 存在。工具参数以当前工具 schema 为准。
4. 宿主支持参考图时，可用已批准的封面或样张作为后续卡片的风格参考，明确其只约束风格，保留每张卡的内容和构图；不得重画已有批准资产。逐卡保存必须出现的准确文字，逐字核对标题、正文、数字、单位和图表关系，检查清晰度、尺寸及整组风格，并实际展示生成结果。发现局部错误时，优先用原图局部修改，明确变更和保留范围，再复核整张；必要时重生。不能靠删关键内容救图；无法核准的内容明确标注，不视为通过。
5. 写 `captionText`、`captionTags`，制作 payload。本地验证使用已授权的本地图源；公网图片托管属于单独的上传/发布动作，须有对应授权。URL fragment 是编码，不是加密，不能装私有内容后公开分享。
6. 将成品图片和 payload.json 保存到本地成果目录，payload 的 src 填相对于 JSON 的本地文件路径。运行 `preview-local.mjs`，保持服务运行并向用户提供本地 URL，在宿主支持时打开页面，检查图片、排序、文案及 ZIP。网页支持拖排后保存顺序、复制文案/提示词、ZIP 下载；重生按钮只复制请求，不会自动调用生图。远程图片须能被浏览器 fetch（含 CORS）；任一图下载失败则不生成伪成功的不完整 ZIP。

```bash
node modes/02-images/scripts/render-snapshot.mjs report.html /tmp/source.png
node modes/02-images/scripts/preview-local.mjs output/session/payload.json
```

payload：`{title, captionTitle?, captionText, captionTags: string[], images: [{src,alt,prompt?}]}`。alt 不带序号；本地预览的 src 是本地图片路径；远程分享另用 make-fragment.mjs，支持 HTTP(S) 或小型测试 data URL。CLI 不负责截图、生图、上传和发帖的自动编排。

## 交付前复看

先检查文件能否打开、实际像素尺寸及顺序是否符合计划；工具无法精确控制尺寸时记录偏差。再按第 4 步对照原文逐卡验图。最后以手机阅读宽度按交付顺序浏览整组：不放大能否读到结论和关键标注？相邻页是否推进了内容？需要细读的数据页可以保留，只调整妨碍理解的密度或顺序。缩小预览不等于手机真机验收。

按交付顺序将全部成稿等宽并排，实际查看总览：比较标题距页边的留白、字号和视觉重心；追踪同一颜色或符号跨页是否仍表示同一含义；检查连续出现的构图是否帮助解释新内容。允许封面、封底与内页有不同节奏。记录具体页码和判断，修改后用最终文件重新拼排复看。

将成品文件名、已核项目和未解决的问题补回对应卡片的制作记录；重做一张时更新该条，并连看前后页。文件检查通过不能替代核字或阅读效果判断。

## 当前边界

代码和本地交付工具已存在；实际 Agent 生图/核字、跨宿主安装及平台发帖仍须验收。不要使用不存在的 `/h2w-images` 命令作为安装承诺；给 Agent 普通自然语言请求即可。
