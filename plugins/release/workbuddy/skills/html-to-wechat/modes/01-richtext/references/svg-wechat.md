# SVG 公众号转换与验收

遇到 SVG、动效或交互时，先检查源码与初始、过程、结束状态。转换器保留并诊断结构与引用，不会理解业务状态或保证公众号兼容；不要仅凭 SVG 节点存在判断通过。

- 要求公众号多步流程时，可用明确标注为模拟的自动播放流程；真实输入、互斥切换和可反复开关的弹窗，不应承诺仅靠 SVG 在公众号可靠运行。
- 单次点击变色、闪动和延迟变色有过特定写法的公众号验证；修改内容、布局、尺寸、覆盖层或时序后是新变体，需重新验收。避免依赖跨元素 ID、CSS 焦点或 `:target` 状态；后者在既有草稿测试中失效。
- 用文章内联 SVG，保留 viewBox、尺寸比例、动画关键属性与内部引用；预览用的 object 容器不能当作公众号复制源码。检查文字、图形裁切、点击热区、初始隐藏状态、时序及循环，覆盖层不得遮挡交互。
- 检查转换报告的 SVG 丢失、动画或样式变化、引用断裂及警告；按输入和用户要求决定保留或调整，不能默默声称兼容。若内容无法可靠转换，说明限制并给出合适的静态或自动演示替代方案。
- 逐项在公众号检查粘贴后、保存关闭重开后及目标手机预览。记录设备、文章组合和结果；未测标待测，不用本地预览代替公众号验收。自动演示需明确提示模拟行为。
