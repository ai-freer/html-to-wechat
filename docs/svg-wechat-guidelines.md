# SVG 转公众号：实现规范与验收依据

本规范用于制作和转换公众号文章中的 SVG。示范库是可复用的实现参考，也是项目能力展示；首要目标是转换后的视觉效果和可用性。它不是微信官方支持清单，也不要求整篇文章采用 SVG。

## 1. 先按目标选实现

| 需求 | 公众号优先方案 | HTML Artifact |
| --- | --- | --- |
| 多步流程、输入模拟、选项、弹窗 | 自动开始、循环播放，以模拟鼠标与点击光圈解释操作；明确标注为演示 | 可用自动演示；真实分支与输入按宿主能力用 HTML/CSS/JavaScript |
| 单步反馈 | 从已通过的 D01 变色、D02 闪动、D06 延迟变色写法开始 | 可直接内联 SVG；实际运行环境仍需检查 |
| 打字、逐项出现、终端、图表 | 使用有对应实测记录的具体实现；不能从某一个动画通过推断整类都可用 | 按需选用示范库，检查阅读节奏与性能 |
| 多次 A/B 切换、返回、弹窗反复开关 | 目前不作为可靠方案交付；改为自动流程或单步互动 | 可使用真实状态管理，不能将其公众号可用性一并承诺 |

证据基线是 [F01 / D01 / D02 / D06 原始组合探针](../samples/probe/wechat-compat/probe-auto-single.html)及其[用户验收记录](../samples/probe/wechat-compat/auto-single-test.md)：2026-11-01 粘贴、保存关闭重开、iOS 预览通过。当前[示范库状态表](../examples/svg-motion/README.md)中的视觉改版和上游衍生组件，未经复测不能继承这项结论。Android 未验证。

## 2. 编写可复用的源码

- 向转换器提供 HTML 内联 `<svg>`。示范页中的 `<object>` 是预览容器，不是公众号复制代码；取 `assets/*.svg` 的 SVG 根节点及其内容放入文章。
- 保留 `xmlns`、`viewBox`、必要尺寸和宽高比例；按手机正文实际宽度设计字号、留白、点击区域，避免只能在桌面看清的小字。
- 单步事件沿用事件目标自身的 `begin="click"` 或 `begin="click+0.8s"`，保留对应的 `dur`、`fill`、`restart` 及节点层级。不要随意改为跨元素 ID 触发链。
- 自动流程沿用明确的 `values` / `keyTimes` / `dur` 时间轴。数值数量对应、时间点递增，检查末尾到开头的衔接，至少观察两轮。
- 装饰与文字不要遮挡点击目标；覆盖层使用 `pointer-events="none"`。扩大热区或改层级也属于行为修改，必须重新验收。
- 不以脚本、外部资源、CSS 焦点、动态样式或片段链接作为公众号交互必需条件。保留这些源码用于 HTML Artifact，不代表公众号保存后会保留其行为。
- 箭头、遮罩、引用、变换等能力分别验证；既有探针曾出现箭头消失、动画静止、初始隐藏内容提前出现，不能仅凭浏览器支持作结论。
- 保留来源、固定上游版本、许可证和修改说明。修改内容、尺寸、色彩、时序或嵌入方式后，标记为新的待验证变体。

## 3. 转换前后都要检查

同一输入分别走网页与 Skill 转换器，使用项目既有的 SVG 保真检查和相关测试。需要修改转换规则时，两套实现同步修复。不能只检查源 SVG 或示范页。

| 检查面 | 必须观察的结果 |
| --- | --- |
| 结构 | SVG 与动画节点、关键属性、必要引用关系保留，无解析错误 |
| 静态画面 | 文本完整、字号可读、背景/边框/圆角正确、图形不裁切、初始隐藏内容未提前出现 |
| 时间轴 | 初始态、中间态、结束态及第二轮与源稿相符；鼠标与画面切换同步 |
| 单步互动 | 点击文字和按钮区域均能命中；即时/延迟反馈符合预期，可重复效果按预期恢复 |
| 复制输出 | 测试实际复制的富文本；预览正确不能替代剪贴板或公众号粘贴结果 |
| 移动阅读 | 按正文宽度检查字与图的比例，避免动画过密；检查等待、循环与阅读是否冲突 |

保真检查能发现转换器损失，但不能模拟公众号保存时的处理。若源稿正常、转换后异常，先修转换器；若转换后正常、公众号保存后异常，记录为平台兼容失败并使用已验证替代方案。

## 4. 公众号验收是发布前门槛

每篇实际文章或新变体在新草稿中依次验证：

1. 粘贴后：完整静态画面、动作、点击、循环。
2. 保存并关闭后重新打开：重复以上检查，尤其是初始态和点击命中。
3. iOS 微信扫码预览：重复检查，观察文字可读性和动画密度；需要 Android 时另行验证。

记录组件版本或提交、文章组合、设备/微信版本（能取得时）、三个阶段的结果和截图/问题。未测记“待测”，失败记具体症状；仅本地通过不得标“公众号已验证”。改版通过后再更新示范库状态表，不覆盖原始探针记录。

## 5. 视觉质量也是验收项

每个示例应有清晰的信息层级、统一的色彩与字体、合理留白和明确操作提示。动画服务于内容理解：标题、主信息和结果必须易读；关键结果保留足够阅读时间。自动演示明确提示“无需点击”，交互示例明确指出热区和预期反馈。按需使用动效，不把所有组件同时无限播放当成文章排版方案。

维护时保留三个层次：原始探针保存兼容性证据；独立 SVG 展示可复用效果；实际文章负责最终效果验收。示范库的视觉改进不能取代后两阶段的验证。
