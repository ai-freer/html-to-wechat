# 给 Agent 的安装入口

用户把本仓库 URL 和“安装总包/某个模式”交给你时，按本文完成安装、验证与使用引导。不要只把命令清单交还给用户。

## 版本与来源

当前版本为 0.2.2，通过 GitHub 源码安装，暂未发布 npm 包，没有 `npx html-to-wechat` 安装命令。只有检出的版本包含本文件、`scripts/build-skills.mjs` 和 `scripts/install-skills.mjs` 时，才可执行以下流程。

- 仓库来源：`https://github.com/ai-freer/html-to-wechat`。已有用户指定的本地源码时直接使用，保留未提交修改，不重新 clone 覆盖。
- 否则 clone 到新目录，读取实际检出版本的 README 和本文，记录 commit。用户指定 ref 时使用该 ref，不猜测发布标签或下载地址。
- 缺少上述文件说明拿到的是旧版：说明版本不匹配，索取用户提供的新源码/安装包；不从无关来源拼补，也不宣称新版已装好。

## 选择能力与安装位置

默认安装总包 `html-to-wechat`，包含四场景和多目标路由。只有用户明确只需单一场景时，选择 `html-to-wechat-richtext`（公众号）、`html-to-wechat-images`（图集）、`html-to-wechat-script`（口播）或 `html-to-feishu`（飞书）。无需同时重复安装总包和独立模式包。

用户指定的位置优先；否则在当前用户项目中安装，避免污染全局。Codex 项目级目录为 `<用户项目>/.agents/skills`，已做本地宿主发现验证。其他宿主先依据其实际配置/官方说明确定 Skill 目录，不把 Codex 路径照搬过去。只有无法确定用户项目或宿主时才问一个必要问题。全局安装须符合用户明确范围。

目标若已存在，先读 manifest/版本并报告差异；安装器会拒绝覆盖。相同包无需重装。版本分叉不要直接覆盖用户修改或同步 Hub。

## 执行安装

需要 Node.js 20.19+、npm；先检查可用性。缺少运行时就说明所缺，不擅自换环境、修改全局配置。若宿主沙箱禁止写入 Skill 目录或联网安装依赖，报告具体阻塞并使用宿主支持的授权流程；不要换成不完整复制、创建符号链接绕过限制，也不要声称安装已完成。

从源码根执行，下面变量由你替换为已确定的**绝对路径**，所有路径加引号。构建目录必须不存在，且不能与源码/安装目标重叠。

```bash
node scripts/build-skills.mjs --out "$h2w_build"
node scripts/install-skills.mjs --from "$h2w_build/html-to-wechat" --dest "$h2w_skills"
```

单模式只替换 `--from` 末尾包名。必须使用构建后的完整包，不能只复制 `skill/modes/`。安装器校验文件哈希、用包内锁文件安装依赖，并在成功后落位；默认不安装浏览器模块、不执行 npm lifecycle scripts，不下载浏览器，也不装飞书 CLI。

需要截图测宽时才按安装包说明补可选浏览器模块，并使用已有浏览器；飞书本地 XML 导出不需要 CLI 或登录。生图、云端创建、上传、部署不是“安装”的隐含步骤。

## 验证安装与交付

1. 检查安装器退出成功、包根 manifest 和 SKILL.md 存在，读取已安装的入口，不继续依赖源码目录。
2. 总包运行 `node "$h2w_skills/html-to-wechat/scripts/local-pair.mjs" --help`。在用户项目中新建一个小型临时 HTML（标题、段落、表格），调用 `--input <文件> --inspect`，核对结构数量，以实际加载运行时依赖。单模式按其 SKILL.md 调用对应的最小本地命令。
3. 验证宿主自动发现。Codex 可在有 CLI 的环境从源码运行 `node tests/codex-discovery.mjs "<用户项目>" html-to-wechat`；没有该能力时不要把文件复制成功等同于自动发现，通过新会话实际触发或说明需要重新加载。不得为了验证修改全局凭据/模型配置。
4. 简短交付来源/ref、安装位置、能力范围、验证结果和下一句使用示例。例如：“把这篇 HTML 转成公众号和飞书，保留正文与表格，先本地输出。”

转换阶段让已安装 Skill 路由：公众号＋飞书本地任务走总包的统一入口；图集和口播按模式执行。CLI 是 Skill 内的 Node 脚本，无须另装同名全局命令。内容完整、视觉检查与平台验收分别报告。

详细开发/手动操作参考 [安装与依赖说明](skill-installation.md)，无需让普通用户逐步执行。
