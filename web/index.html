从文章生成图片需要 Agent 和生图工具；网页不直接生图。

01 · 复杂 HTML → 公众号任务示例

请使用 html-to-wechat Skill 的公众号模式处理我提供的原始 HTML。结合必要截图检查全部正文、隐藏面板和图表，先说明需要展开、保留或降级的内容，再生成明确的转换 plan，调用转换器输出 wechat-ready.html。核对遗漏和视觉差异，先本地交付，不发布。

交付：转换后的 HTML 与差异说明。最终仍需在公众号编辑器检查保存和手机效果。

02 · 长文章 → 小红书图集任务示例

请使用 html-to-wechat Skill 的图集模式分析我提供的文章，保留数据来源与时间，先给出卡片结构、每张文案和统一风格的生图提示词。确认生图工具与费用范围后再生成图片，核验后输出图集和预览链接；不要自动上传或发布。

交付：分镜、文案与图集结果。生图依赖宿主工具，素材托管另行选择。

03 · HTML 长文 → 口播稿任务示例

请使用 html-to-wechat Skill 的口播模式处理我提供的 HTML。先提取并核对各章节、表格和图表，再改写成适合朗读的 Markdown 口播稿。标注原文日期与预测，不编造事实；交付字数、估计时长和删减说明，供网页预览下载。

交付：Markdown 成稿；打开口播页粘贴，或使用 Skill 生成的预览链接。

04 · HTML → 飞书文档任务示例

请使用 html-to-wechat Skill 的飞书模式处理我提供的 HTML。优先保留可编辑的原生文档块，先评估复杂布局和图表；如果建议 HTML 内容块，请说明取舍并等我选择。先本地导出 XML 和资源包、核对完整性，不登录新账号、不创建云端文档。

交付：XML 与同目录资源包；创建云端文档前明确账号、目的地与授权。

飞书与其他可选依赖按需准备

公众号基础转换和飞书本地 XML 导出无需浏览器、飞书 CLI 或登录。需要截图、生图或飞书云端创建时，再由 Agent 按任务准备对应能力；安装不会自动上传或发布内容。
